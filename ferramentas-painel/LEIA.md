# Scripts que geram os painéis (cópia de 22/10/2026)
Python 3 (stdlib + `numpy`/`faster_whisper` só para transcrever virais) e Node + Playwright (só para testar o painel no navegador). Os scripts foram escritos numa pasta temporária e têm **caminhos absolutos fixos** (`/tmp/claude-0/.../scratchpad/...`): ao reaproveitar, trocar as constantes `SP`/`SPD`/`R6` no topo de `r8/p8.py`, `r10/build13.py` e `r10/p11.py` pela pasta onde esta cópia ficar. Ordem: `r6/prompts.py` (identidade da Nora, campos da Central de imagens) → `r8/p8.py` e `r8/build8.py` → `r9/p9.py`, `r9/build9.py` → `r10/scripts10.py`, `r10/mov10.py`, `r10/p11.py`, `r10/p12.py` → `r10/build13.py` (o mais atual; `python3 build13.py` regenera PAINEL-NORA30 a 33 a partir de `PAINEL-MODELO.html`). `pacote_r004.json` é a base do pacote. Se algo quebrar, o formato do pacote está descrito no `CLAUDE.md` (dados do painel) e o painel é só HTML com `const PACOTE = {...}`.
